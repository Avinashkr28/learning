# CV Creation Webpage

This project is a simple CV/Resume webpage created using HTML.

## Features
- Resume layout using HTML
- Contact information section
- Skills section
- Education details
- Experience details
- Achievement list using bullet points
- Border around the webpage
- Horizontal line using <hr>

## Technologies Used
- HTML5

## Project Structure
- index.html → Main HTML file

## How to Run
1. Download or clone the repository
2. Open the `index.html` file in any web browser
